# Atlas Dashboard Template

A self-contained responsive dashboard template with KPI cards, canvas charts, regional progress, activity updates, and a campaign performance table.

## Open

Open `index.html` in a browser.

## Customize

- Update metric values in the KPI card markup.
- Edit chart data in the `<script>` block near the bottom of `index.html`.
- Adjust colors in the `:root` CSS variables.
- Replace campaign rows in the table body.
